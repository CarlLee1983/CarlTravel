# 台灣景點官方資料來源盤點

回應票：[02-official-sources-survey](../issues/02-official-sources-survey.md)
查閱日期：2026-10-15（下文所有連結皆於當日查閱）

標記說明：**〔已驗證〕**＝當日實際讀取一手來源或下載資料確認；**〔推論〕**＝依已驗證事實推得、未直接證實；**〔未查證〕**＝僅有二手資料或未能讀取。

## 結論

建議的查證順序是：景點經營者自己的官網，其次是該景點的主管機關網站，再來是交通部觀光署的「臺灣觀光資訊網」頁面，觀光署開放資料只用來找景點與定位。Google 地圖、部落格、旅遊平台都不算官方。

這個順序最關鍵的依據，是對「臺北市立兒童新樂園」三個來源的實測比對。

| 項目 | 觀光署開放資料（Attraction JSON） | 臺灣觀光資訊網景點頁 | 景點官網 tcap.taipei |
| --- | --- | --- | --- |
| 開放時間 | 空 | 有 | 有（細分寒暑假、休園日） |
| 票價 | 空 | **缺** | 有（全票、優待票、免費對象） |
| 交通／停車 | 空 | 有（附近站點與停車場的直線距離） | 有 |
| 親子／無障礙 | 空 | 無 | 有（哺集乳室、娃娃車與輪椅出借、無障礙通道） |
| 更新日期 | `UpdateTime` 2026-06-10，但欄位是空的 | 無 | 有（「更新日期 115-10-15」） |

〔已驗證〕來源：[開放資料 JSON](https://media.taiwan.net.tw/XMLReleaseAll_public/v2.0/Zh_tw/Attraction-json.zip)、[觀光資訊網景點頁](https://www.taiwan.net.tw/m1.aspx?sNo=0001090&id=A12-00382)、[官網營運時間及收費](https://www.tcap.taipei/cp.aspx?n=EE083F2DED91AB99)、[官網貼心服務](https://www.tcap.taipei/cp.aspx?n=E73F99246F336F7E)。

## 一、各類來源

### 1. 景點自營官網（含公營事業、民間業者）

可信度最高，是唯一可能同時有票價、休園日、親子與無障礙設施的來源。

- 〔已驗證〕兒童新樂園官網用 HTML 文字呈現營運時間、票價、哺集乳室（4 間）、娃娃車與輪椅出借、無障礙通道，並標示頁面更新日期，以 curl 和 WebFetch 都能直接讀取。來源同上表。
- 〔已驗證〕兒童新樂園官網頁尾的「政府網站資料開放宣告」連到臺北大眾捷運公司的宣告，可見經營者是北捷，不是市府局處：[宣告](https://www.metro.taipei/ct.asp?xItem=1233560&ctNode=70048&mp=122035)。因此「誰是經營者」要從官網頁尾判斷，不能只看景點名稱。
- 〔推論〕民營景點（農場、觀光工廠、私人樂園）的官網沒有開放授權，事實可以轉述，但不能大段複製（見第三節）。這些官網的品質與更新頻率差異很大，所以每一節都要記下查證日期。
- 觀光工廠：〔未查證〕經濟部產業發展署的評鑑名單據報導列在「觀光工廠自在遊」[taiwanplace21.org.tw](https://www.taiwanplace21.org.tw/)（HTTP 200 可連線，但內容與名單未讀）。目前只有新聞報導指出，業者自稱的觀光工廠不一定通過評鑑：[食力](https://www.foodnext.net/news/industry/paper/5739291958)（二手資料）。

### 2. 主管機關網站（林業保育署、國家公園署、國家風景區管理處等）

這類網站對自己管轄的園區有權威性，票價與規則通常最完整。

- 〔已驗證〕農業部林業及自然保育署的「台灣山林悠遊網」[recreation.forest.gov.tw](https://recreation.forest.gov.tw/) 可直接讀取。單一遊樂區頁採 `/Forest/RA?typ_id=<代碼>` 格式。以[阿里山](https://recreation.forest.gov.tw/Forest/RA?typ_id=0500001)為例，頁面以 HTML 文字列出開放時間、各票種票價、停車費、交通方式、無障礙路線、哺集乳室與推車提醒，但沒有頁面更新日期，同一頁的部分數據（海拔、電話）前後也不一致。
- 〔已驗證〕內政部國家公園署 [nps.gov.tw/ch](https://www.nps.gov.tw/ch) 是 Next.js 前端渲染：原始 HTML 只有約 2.7KB，WebFetch 只讀到「undefined」。[陽明山](https://www.ymsnp.gov.tw/)與[太魯閣](https://www.taroko.gov.tw/)的網域，抓到的也是同一套殼頁（純文字中只有 53 個中文字）。[墾丁](https://www.ktnp.gov.tw/)則是傳統 HTML，可以直接讀取。
- 〔推論〕國家公園署的頁面要用真實瀏覽器（Playwright 或 Chrome 工具）渲染後才能讀；若做不到，就標示「原文無法讀取」。這一點沒有實測。
- 〔已驗證〕林業保育署的[政府網站資料開放宣告](https://www.forest.gov.tw/opendata)：網站上的資料以無償、非專屬方式開放利用，但「應註明出處」，不包括商標與機關標誌，另外聲明須經同意的影音或圖像也不在授權範圍內。

### 3. 交通部觀光署：臺灣觀光資訊網

- 〔已驗證〕[www.taiwan.net.tw](https://www.taiwan.net.tw/) 以伺服器端渲染 HTML，curl 與 WebFetch 都能讀到完整內容。景點頁的網址格式是 `m1.aspx?sNo=0001090&id=<編號>`，例如 `A12-00382`。注意：根網址會 302 轉到英文版 eng.taiwan.net.tw，要直接打中文頁的路徑。
- 〔已驗證〕景點頁有開放時間、地址、電話、交通（列出附近站點與直線距離）、停車場與官網連結，但兒童新樂園這一頁沒有票價，也沒有更新日期；頁尾只寫「中華民國交通部觀光署 版權所有」。
- 〔已驗證〕活動頁（例如[觀鳥馬拉松](https://www.taiwan.net.tw/m1.aspx?sNo=0001019&lid=081709)）的「交通資訊」區塊是空的，可見欄位不一定有內容。
- 〔已驗證〕`robots.txt` 只有 `User-agent: *`，沒有 Disallow。
- 可信度：屬於官方彙整，但是二手。〔推論〕它的資料多半來自地方政府回傳，時效比不上景點官網，適合拿來交叉比對，以及找到官網連結。

### 4. 交通部觀光署：觀光資訊資料庫（開放資料）

- 〔已驗證〕data.gov.tw 資料集 [7777「景點 - 觀光資訊資料庫」](https://data.gov.tw/dataset/7777)：提供機關是交通部觀光署，**每 1 日**更新，免費，授權為政府資料開放授權條款第 1 版，欄位依[觀光資料標準 V2.1](https://media.taiwan.net.tw/Upload/觀光資料標準V2.1.pdf)。可直接下載 [JSON](https://media.taiwan.net.tw/XMLReleaseAll_public/v2.0/Zh_tw/Attraction-json.zip) 或 [XML](https://media.taiwan.net.tw/XMLReleaseAll_public/v2.0/Zh_tw/Attraction-xml.zip)，不需要金鑰。同系列另有活動（[7778](https://data.gov.tw/dataset/7778)）與旅館民宿（[7780](https://data.gov.tw/dataset/7780)）。
- 〔已驗證〕2026-10-15 下載的 JSON 標頭為 `UpdateTime 2026-10-15T02:30:03+08:00`、`UpdateInterval 86400`、`ProviderID A15010000H`，共 6,185 筆景點，另附 `AttractionServiceTimeList`（77 筆結構化營業時間）與 `AttractionFeeList`（38 筆結構化收費）。
- 〔已驗證〕各欄位**有值的筆數**（總數 6,185）：ServiceTimeInfo 1,625（26%）、TrafficInfo 749（12%）、FeeInfo 502（8%）、WebsiteURL 450（7%）、ParkingInfo 78（1.3%）、Facilities 60（1%）。沒有專門的無障礙或親子欄位。
- 〔已驗證〕熱門景點也可能整筆只有名稱和座標：國立臺灣科學教育館、兒童新樂園的時間、票價、交通、停車、官網欄位全是空的，但 `UpdateTime` 卻落在 2026 年。
- 〔推論〕因此 `UpdateTime` 不能當作內容的查證日期，資料集也不能當作開放時間或票價的依據。它的用途是建立景點候選清單、取得官方名稱、地址、座標與 `AttractionID`，作為「官方名稱 + 地址」識別的輔助。

### 5. TDX 運輸資料流通服務

- 〔已驗證〕[tdx.transportdata.tw](https://tdx.transportdata.tw/) 首頁是前端渲染的 SPA：原始 HTML 約 1.6KB，WebFetch 只讀到「TDX」。
- 〔未查證，二手〕據教學文件，觀光景點 API 是 `/v2/Tourism/ScenicSpot`，需要註冊會員並經審核，以 Client Id 與 Secret 換取 Access Token（有效 1 天）；自 2024-04-29 起依訂閱方案限制呼叫次數：[TDX 範例程式 repo](https://github.com/tdxmotc/SampleCode)、[bookdown 教學](https://bookdown.org/chiajungyeh/TDX_Guide/)。TDX 的授權與署名規範沒有找到一手條文。
- 〔推論〕TDX 的觀光資料應該與上一項同源，但需要金鑰，v1 不值得接。

### 6. 縣市政府觀光旅遊網

可信度：地方官方彙整，與觀光資訊網同級。可讀性實測如下〔已驗證〕：

| 網站 | 結果 |
| --- | --- |
| [臺北旅遊網](https://www.travel.taipei/zh-tw) | **403，Cloudflare「Just a moment」挑戰頁**，curl 與 WebFetch 都擋 |
| [高雄 khh.travel](https://khh.travel/) | **403，Cloudflare 挑戰頁** |
| [新北市觀光旅遊網](https://newtaipei.travel/) | 200，可讀（純文字約 1,800 個中文字） |
| [臺南 twtainan.net](https://www.twtainan.net/) | 200，首頁文字少（約 850 個中文字），內頁未測 |
| [臺中觀光旅遊網](https://travel.taichung.gov.tw/) | 200，首頁文字很少（約 440 個中文字），〔推論〕可能部分由前端渲染 |

### 7. 政府資料開放平臺 data.gov.tw

- 〔已驗證〕[data.gov.tw](https://data.gov.tw/dataset/7777) 的資料集頁可直接讀取，頁上的詮釋資料包括提供機關、更新頻率、授權、下載網址與聯絡人。
- 它本身不是資料來源，而是目錄。縣市自有的景點資料集（如桃園、新北、臺中）也列在上面〔未逐一查證〕，品質應逐一判斷。

### 8. Google 地圖與商家檔案：**不算官方**

- 〔已驗證〕Google 說明文件寫明，使用者可以對商家檔案建議編輯，商家有 4 天可以接受或拒絕；若有其他公開資訊佐證，Google 可能自動發布更新，必要時也會不經商家審核就套用使用者的編輯：[Understand Google updates on your Business Profile](https://support.google.com/business/answer/3480441?hl=en)。因此 Google 上的營業時間或電話，可能不是經營者自己提供的。
- 〔已驗證〕[Google Maps Platform 服務條款 §3.2.3](https://cloud.google.com/maps-platform/terms)（Last modified 2026-08-26）規定「No Scraping」：不得在服務之外 store 或 reshare Google Maps Content，例如「copy and save business names, addresses, or user reviews」；「No Caching」除非服務專屬條款明文允許。
- 〔已驗證〕[Google 地圖／Google 地球附加服務條款](https://www.google.com/help/terms_maps/)（Last Modified 2026-01-27）第 2 節禁止複製內容（另有許可者除外）、大量下載，以及用 Google 地圖建立或擴充其他地圖相關資料集。
- 用法建議：頁面上只放「在 Google 地圖開啟」的連結，作為導航入口。Google 上的營業時間、評論、照片都不寫進景點內容，最多在研究紀錄裡作為「去官網再確認」的線索。

### 不算官方的來源

部落格、旅遊平台（KKday、Klook、Trip.com 等）、新聞報導、Google 評論與在地嚮導照片、社群貼文都不算官方。它們在 CarlTravel 裡只有兩種角色：作為 Carl 貼來的「來源」，提供原作者心得（依 01 號票轉述並署名）；或作為查證線索。它們不能用來填官方資訊分節，也不能用來填親子／無障礙清單裡的「有」或「無」（依 01 號票，這兩個值都要有可查來源）。

〔推論〕景點自己經營的 Facebook 或 Instagram 粉專，屬於經營者自己的發言，可信度接近官網。但貼文是一次性的公告、時效短，而且常需要登入或 JS 才能讀，建議只在官網沒寫的臨時公告（休園、颱風）時引用，並記下貼文日期。

## 二、建議的官方資訊優先順序

1. **景點經營者自己的官網**（公營機構、公營事業或民間業者）：採用有標示更新日期的頁面；票價與親子設施只認這一層，或第 2 層。
2. **主管機關網站**：林業保育署（台灣山林悠遊網）、國家公園署與各管理處、觀光署各國家風景區管理處。若主管機關就是經營者，這一層與第 1 層合一。
3. **交通部觀光署 臺灣觀光資訊網景點頁**，以及**縣市政府觀光旅遊網**：用來交叉比對交通與停車資訊、取得官網連結。與第 1 層衝突時，以第 1 層為準；若差異重大，標示「資料不一致」。
4. **觀光署開放資料（data.gov.tw 7777）**：只用來定位景點，取得官方名稱、地址、座標與 ID；不用來支撐時間或票價。
5. **經營者自己的社群粉專**：只用於臨時公告。

第 1 到 3 層都查不到的項目，填「官方未公布」或「未知」，不要用 Google 地圖或心得文補上。

## 三、授權要點

- 〔已驗證〕[政府資料開放授權條款第 1 版](https://data.gov.tw/license)（104 年 7 月 27 日訂定）：不限目的、時間與地域，非專屬、不可撤回、免授權金，可以重製、改作、散布，也可以開發產品或服務，文字上涵蓋商業利用。**第三條第（二）項**規定，使用時須依附件的顯名聲明標示原提供機關，「未盡顯名標示義務者，視為自始未取得開放資料之授權」。顯名格式為「提供機關／單位 [年份] [開放資料釋出名稱與版本號]」，並附條款連結。第四條說明本條款與 CC BY 4.0 相容；第六條說明機關不保證資料正確。
- 〔已驗證〕觀光署的[觀光多媒體開放資料](https://media.taiwan.net.tw/)平台也採用同一條款，圖片沒有另訂專門規範。
- 〔已驗證〕各機關網站常見的「政府網站資料開放宣告」（如[林業保育署](https://www.forest.gov.tw/opendata)、[北捷／兒童新樂園](https://www.metro.taipei/ct.asp?xItem=1233560&ctNode=70048&mp=122035)）採寬鬆授權，但共同條件是「應註明出處」、不得惡意變更、不包括商標與標誌，而且特別聲明的影像或專文不在授權範圍內。〔未查證〕臺灣觀光資訊網頁尾只有「版權所有」，當日沒有找到網站層級的資料開放宣告，所以觀光資訊網頁面上的文字應視為一般著作，只轉述事實並附連結。
- 〔已驗證〕[著作權法第 9 條](https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=J0070017&flno=9)列出不受著作權保護的標的，包括公文、「數表、表格」，以及單純傳達事實的新聞報導語文著作。〔推論〕開放時間、票價這類事實資訊本身難以主張著作權，但景點官網上的介紹文字、照片受保護。轉述的分寸與引用上限交給 [03 號票](../issues/03-quotation-copyright-bounds.md)決定。
- 〔推論〕給 CarlTravel 的實作建議：每一條官方資訊都附來源連結與查證日期（01 號票已經要求）。若直接使用開放資料欄位，就在公開頁的來源清單加上顯名聲明，例如「交通部觀光署 2026 觀光資訊資料庫－景點 v2.0」，並附條款連結。v1 不放照片，所以圖片授權問題暫時不會發生。

## 未能查證的項目

- TDX 的資料授權與署名條款原文，以及觀光 API 現行的呼叫額度（只有二手資料）。
