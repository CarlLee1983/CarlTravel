# 視覺方向

Type: prototype
Status: resolved
Assignee: Carl
Blocked by:

## Question

CarlTravel v1 的網站要長成什麼樣子？頁面種類與景點頁的分節順序已在[網站頁面範圍與瀏覽方式](07-site-pages-and-browsing.md)定案，這張票只決定樣式：

- 版面風格、字型與配色。網站不放照片，畫面只有文字與連結，要靠什麼撐起視覺？
- 景點頁上，三類資訊（官方資訊、原作者心得、Agent 建議）如何在視覺上區分；「官方未公布」「資料不一致」「原文無法讀取」「資料可能過期」這幾種狀態，以及親子清單的有／無／未知，分別怎麼呈現。
- 首頁的景點卡片、搜尋框與篩選的呈現方式。
- 地圖連結（Google Maps URLs、OSM）的呈現方式。
- 要沿用 CarlKitchen 的哪些視覺元素，哪些不沿用。

需在 360–1920 寬度下不出現水平捲動，並通過 axe 檢查（見[自動品質檢查與發布關卡](06-quality-gates.md)）。原型只作討論素材。

## Prototype — 待 Carl 選擇

2026-10-15：Carl 同意比較三個方向：[互動原型](../prototypes/10-visual-direction/index.html)（[啟動方式](../prototypes/10-visual-direction/README.md)）。A 旅行筆記延續 CarlKitchen 的米白底與明體標題；B 出遊工具以側欄篩選和緊湊列表呈現；C 地方導覽採縣市分組與景點頁目錄。三者使用相同虛構資料，提供首頁、景點示例與可操作的搜尋篩選。

已檢查三種方向的兩種頁面在 360、768、1920 像素下無水平溢出，以及搜尋、清除、縣市篩選、景點導航與鍵盤切換。原型供視覺討論，尚未選定方向，本票保持開放；不代表正式網站實作或驗收完成。


## Answer

Carl 於 2026-10-15 選定「A 的字體、B 的首頁、C 的景點目錄」。組合版保留在[原型 D](../prototypes/10-visual-direction/index.html?variant=D&page=home)，原始 A／B／C 供對照。

- 標題採 A 的明體字型與 600 字重，內文及表單保留黑體，延續 CarlKitchen 的閱讀風格。
- 首頁採 B 的桌面側欄篩選與緊湊景點列表；窄螢幕改為上方篩選、下方列表。
- 景點頁採 C 的左側固定章節目錄與右側單欄內容；窄螢幕目錄改為上方可橫向捲動的章節連結，沿用已定案的分節順序。
- 官方資訊、原作者心得與 Agent 建議保留文字標籤；未知、衝突、無法讀取、過期及親子設施狀態均以文字搭配色彩表示。
- 地圖使用有名稱的文字連結，不嵌入地圖；虛構原型中的地圖按鈕保持停用。

組合原型以 B 的藍灰配色統一兩頁，這是本次整合的預設呈現，不另列為 Carl 指定的配色要求。實作時以此原型與上述決策為參考，正式頁面仍須通過完整驗收。
