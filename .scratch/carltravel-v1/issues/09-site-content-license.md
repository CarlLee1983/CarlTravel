# 網站內容的授權宣告

Type: grilling
Status: resolved
Assignee: Carl
Blocked by:

## Question

公開的景點內容要採用什麼授權，例如 CC BY 4.0、CC BY-NC 4.0，或保留所有權利？這個授權要怎麼與內容中他人的部分並存？他人的部分包括：

- 原作者心得的直接引文（依票 03，屬於合理引用，不在本站授權範圍內）；
- 依政府資料開放授權條款使用的官方事實（必須標示提供機關）；
- 臺灣觀光資訊網等「版權所有」來源轉述而來的事實。

需要決定的事項：授權的條款與適用範圍（景點文字、schema 與程式碼是否分開授權）；授權宣告放在哪裡（頁尾、關於頁、每個景點頁）；如何標出「不適用本站授權」的引文與標示。若結論符合 ADR 門檻，就寫成 ADR。

## Answer

以下由 Carl 於 2026-10-15 確認。理由與取捨記在 [ADR-0002](../../../docs/adr/0002-content-license-cc-by-nc.md)。

### 條款與範圍

- 本站撰寫的景點內容（`content/` 下的摘要、轉述、Agent 建議、親子清單等）採 **CC BY-NC 4.0**。
- 程式碼、Zod schema 與 skill 採 **MIT**，授權檔放在根目錄的 `LICENSE`。`content/` 另外宣告採 CC BY-NC 4.0，README 說明兩者如何劃分。

### 宣告位置

- 每一頁的頁尾放一行短宣告，例如「本站撰寫的內容採 CC BY-NC 4.0，引文與官方資料除外」，並連到關於頁。景點頁不另外重複。
- 完整版放在關於頁的授權段落（票 07 預留的位置），內容包括條款連結、不適用範圍，以及給轉載者的建議署名格式：「〈景點名〉，CarlTravel，<頁面網址>，CC BY-NC 4.0」，同時提醒轉載時要移除或另外標明引文。
- 每一頁的 `<head>` 加上 `<link rel="license">`，指向 CC BY-NC 4.0 條款。

### 不適用本站授權的部分

- 原作者引文：沿用票 03 的引文格式（附原作者與來源連結）。關於頁統一聲明引文的著作權屬原作者，不在本站授權範圍內；引文旁不另加標記。
- 官方事實：關於頁聲明事實本身不受著作權保護，本站也不主張權利。
- 臺灣觀光資訊網等「版權所有」的頁面：只轉述事實並附連結，不另外標示。
- 政府開放資料：依政府資料開放授權條款第 1 版的附件格式顯名，例如「交通部觀光署 2026 觀光資訊資料庫－景點 v2.0」，並附[條款連結](https://data.gov.tw/license)，放在景點頁的「來源與官方出處」。

### schema 修正（修正票 04）

- `officialRefs[]` 新增 `kind`：`page`（預設）或 `openData`。`kind: openData` 的條目必填顯名字串（提供機關、年份、資料集名稱與版本）。
- `superRefine` 新增一條規則：景點有 `tourismId` 時，`officialRefs` 至少要有一筆 `kind: openData`；缺少就讓 schema 失敗。用 `tourismId` 定位也算利用開放資料，所以一律要求顯名。
