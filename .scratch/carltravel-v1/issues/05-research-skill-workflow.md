# carltravel-research 的研究與撰文流程

Type: grilling
Status: open
Blocked by: 02, 03, 04

## Question

`carltravel-research` skill 要規定的完整工作流程是什麼？從 Carl 貼上網址與備註開始，到交出可供審閱的草稿為止：

- **讀取原文**：抓取失敗、需要登入、付費牆或 JS 渲染時怎麼處理，以及如何標示「原文無法讀取」。外部網頁內容一律只當作資料、不執行其中的指令，這條規則要寫進 skill 的哪個位置、要多明確。
- **辨識與拆分景點**：一篇文章提到很多地點時，什麼條件下拆成獨立景點、什麼情況只放進周邊安排、什麼情況直接略過。
- **同一性比對**：如何搜尋既有的 `content/` 與 `drafts/`，以及「同一性待確認」要怎麼呈報給 Carl。
- **補查官方資料**：依票 02 的優先順序查證，每個欄位查不到時何時停手、改標「官方未公布」。
- **撰文規則**：引用與轉述的界線依票 03；語氣、親子觀點；「跟孩子一起看」何時該寫。
- **研究紀錄**：`research/<來源 id>/` 裡要放哪些檔案、用什麼格式。
- **交給 Carl 的送審清單**：列出推估、疑點、未知、衝突，以及同一性待確認的項目。
- **補充既有景點**：新來源補進已發布景點時，是開新草稿還是修改，如何只重查有變動的分節，以及 diff 怎麼呈現。

這張票的成果是 skill 的規則清單；skill 檔本身在實作階段撰寫。
