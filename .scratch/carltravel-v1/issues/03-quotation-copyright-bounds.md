# 引用、轉述與著作權界線

Type: research
Status: resolved
Blocked by:

## Question

依台灣著作權法（第 52 條合理引用、第 65 條合理使用的判斷基準，以及相關判決或智慧局函釋），個人非營利網站在轉述與引用部落格旅遊文章時，界線在哪裡？要求如下：

- 已決定的規則是「直接引用每段約 50 字以內，每個來源最多兩段，其餘轉述並署名、附連結」。這套規則是否站得住？有沒有需要收緊或可以放寬的地方？
- 「事實」不受著作權保護（例如營業時間、地址）與「表達」受保護的分界，以及整理多篇文章的行程安排是否可能構成改作。
- 政府網站內容與開放資料的引用規則，並與票 02 對照。
- 圖片方面：只放原文連結、不嵌入圖片是否足夠。嵌入地圖（Google Maps 嵌入、OpenStreetMap）的條款。

成果寫在 [research/quotation-copyright.md](../research/quotation-copyright.md)，每一項結論都要附法條或一手來源。這不是法律意見，只用來界定 skill 的保守預設值。

## Answer

完整研究見 [research/quotation-copyright.md](../research/quotation-copyright.md)（查閱日期 2026-10-15，不是法律意見）。

- **「每段約 50 字、每個來源最多兩段」維持不變，但它不是安全港**：智慧局表示合理使用沒有字數門檻。要適用第 52 條，必須同時滿足三點：頁面以本站自己的內容為主、引文和本站文字明確區隔、註明出處。依此補上三項限制：引文只能放在轉述之後當佐證；不引用原文的清單、行程或總評；轉述不能完整到讀者不必再看原文。
- **事實可以自由使用，轉述才是風險所在**：營業時間、地址、票價這類事實依第 10 條之 1 不受保護。逐句換字的轉述可能構成改作，而且不受第 52 條保護。所以寫法應該是先抽出事實和觀點，再用自己的話重寫；非引文的部分沿用 CarlKitchen ADR 0009 的 12 字重疊檢查。整套搬用單一作者的景點清單與排列順序，可能碰到編輯著作的問題（這一點是推論）。
- **政府內容**：第 50 條只適用於機關本身具名發表的著作，委外撰寫的文章與照片多半不適用。開放資料一定要依格式標示提供機關。
- **地圖**：v1 只放連結，不嵌入地圖。Google 用 Maps URLs，不需要 API key；另外附一個 OpenStreetMap 連結。圖片只附原文連結即可，單純連結不涉及重製與公開傳輸。
- **契約限制另計**：Google 地圖的條款禁止複製商家名稱與地址，所以 Google 地圖只能拿來發現資料有落差，不能從上面轉錄數值。這與票 02 的結論一致。
- **尚未查證**：判決原文（司法院系統擋自動連線）、嵌入式連結的函釋原文、行程清單是否構成編輯著作、部落格「禁止轉載」聲明的契約效力。
