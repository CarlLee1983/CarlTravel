# 台灣景點官方資料來源盤點

Type: research
Status: resolved
Blocked by:

## Question

Agent 補查台灣景點的開放時間、票價、交通停車、親子與無障礙設施時，有哪些「官方」來源可以用？要求如下：

- 每類來源的可信度、資料涵蓋的欄位、更新頻率，以及 Agent 能否直接讀取（是否需要 JS 渲染、是否擋爬蟲）。來源類別包括：景點自營官網、交通部觀光署（含觀光資訊資料庫／開放資料 API）、縣市政府觀光旅遊網、國家公園與林業保育署等主管機關、政府資料開放平臺、Google 地圖或商家頁。
- 授權條款：例如政府資料開放授權條款，以及轉述或引用時的署名要求。
- 建議的「官方資訊優先順序」，並說明哪些來源**不算**官方（部落格、旅遊平台、Google 評論等）。

成果寫在 [research/official-sources.md](../research/official-sources.md)，每一項事實都要附一手來源連結。這張票的結論會成為 carltravel-research skill 查證順序的依據。

## Answer

完整研究見 [research/official-sources.md](../research/official-sources.md)，查閱日期為 2026-10-15。

- **查證優先順序**：
  1. 景點經營者自己的官網。
  2. 主管機關網站，例如林業保育署、國家公園署、國家風景區管理處。
  3. 交通部觀光署「臺灣觀光資訊網」與縣市觀光網，主要用來交叉比對交通與停車資訊。
  4. 觀光署開放資料（data.gov.tw 7777）只用來**定位**景點，取得官方名稱、地址、座標與 ID，不拿來查證開放時間、票價或設施。實測 6,185 筆資料中，開放時間只有 26% 有值、票價只有 8%，也沒有親子或無障礙欄位；資料中的 `UpdateTime` 不能當作查證日期。
- **不算官方的來源**：Google 地圖與商家檔案（使用者可編輯，Maps Platform 條款也禁止儲存店名、地址）、部落格、旅遊平台、新聞。景點頁只放「在 Google 地圖開啟」的連結。
- **授權**：政府資料開放授權條款第 1 版可以商用，但未依格式標示提供機關的話，「視為自始未取得授權」。各機關網站要求註明出處，且不包含商標與特別聲明的圖文。臺灣觀光資訊網只寫「版權所有」，所以只轉述事實並附上連結。
- **Agent 的讀取限制**：國家公園署及陽明山、太魯閣網域是前端渲染；TDX 需要金鑰；臺北旅遊網與高雄 khh.travel 會回應 Cloudflare 挑戰頁（403）。遇到這些網站，skill 需要準備替代做法，例如改用瀏覽器工具，或標示「官方頁面無法讀取」。
- **尚未查證**：TDX 的授權與額度、臺灣觀光資訊網有沒有站級的開放宣告、國家公園署頁面經瀏覽器渲染後的內容、縣市觀光網的更新頻率。
