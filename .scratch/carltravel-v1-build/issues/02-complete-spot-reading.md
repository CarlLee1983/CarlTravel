# 02: 完整景點內容與資訊狀態

**What to build:** 讀者可完整閱讀景點、分辨三種資訊與所有不確定狀態；不合規的內容在公開前被擋下。

**Blocked by:** [01：第一個景點可瀏覽](01-first-browsable-spot.md)

**Status:** done

**Parent:** [CarlTravel v1 規格](../../carltravel-v1/issues/11-carltravel-v1-spec.md)

- [x] 完成母規格的單一 YAML 模型、穩定 id、22 縣市與官方行政區驗證、封閉類型／環境、摘要上限、年齡範圍或 unknown，以及來源與官方出處的有效參照。
- [x] 依規格固定順序呈現親子清單、費用時間、交通停車、可選設施與跟孩子一起看、原作者心得、Agent 建議、周邊安排及來源；基本景點仍可獨立展示，選填分節不強迫填造。
- [x] 逐條官方事實附出處，各節有日期；ok、官方未公布、至少兩方說法的衝突與聯絡提示、原文無法讀取均有文字。五項親子清單有／無須附出處，未知不當成沒有。
- [x] 原作者心得署名與附連結；引文每來源最多兩段、每段硬上限60字；引文外禁用第一人稱。跟孩子一起看的事實附出處，活動標為 Agent 建議。
- [x] 超過12個月顯示過期提示並只警告；提供 Google Maps URLs 與 OpenStreetMap 文字連結，不嵌入地圖。
- [x] 使用觀光署定位 ID 必有開放資料顯名；定位顯名與不可讀來源的公開溯源條目算有效使用，其餘未使用來源／出處報錯。不可讀來源無心得與引文仍可通過。
- [x] 內容關卡拒絕無效參照、缺出處、無效行政區、引文超限、第一人稱與景點圖片；正反 fixture 透過公開驗證入口測試，不只測內部欄位函式。
- [x] 補齊資料模型及內容檢查的文件，標明實作採母規格而非舊格式原型；完整視覺與全站授權由下一票處理。
