# 05: 本機草稿與修訂預覽

**What to build:** Carl 可在本機預覽新草稿與既有景點修訂，正式建置則保留已發布版本且不帶出私人內容。

**Blocked by:** [02：完整景點內容與資訊狀態](02-complete-spot-reading.md)

**Status:** ready-for-agent

**Parent:** [CarlTravel v1 規格](../../carltravel-v1/issues/11-carltravel-v1-spec.md)

- [ ] 正式內容與本機草稿使用同一 schema；草稿由資料位置識別，開發才載入草稿，同 id 草稿優先並顯示修訂中標記。
- [ ] 新草稿與研究紀錄不進 Git或公開資產；以虛構資料驗證追蹤／輸出邊界，不把真實私人資料當測試 fixture。
- [ ] 補充既有景點可複製成同 id 草稿並取得差異；正式內容在核准前不被修改。
- [ ] 正式建置只載入正式內容：新草稿id及專有文字不出現；同id修訂的原正式頁存在但修訂專有文字不出現。開發後切回正式建置仍成立。
- [ ] 已有 sitemap 或索引時沿用同一正式載入邊界；本票以頁面及內容輸出驗證完成，完整 sitemap／Pagefind外洩檢查由發布票整合。
- [ ] 對有效與無效草稿、草稿圖片、模式切換與同id覆蓋提供正反案例；錯誤不以放寬schema或混讀正式資料解決。
- [ ] 更新本機預覽、差異檢視、資料隔離與快取行為的架構／操作文件。
