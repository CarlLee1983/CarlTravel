# 03: 網站視覺、授權與基本頁面

**What to build:** 讀者能在手機與桌面使用選定的設計閱讀網站，並理解授權、免責與無效網址的處理。

**Blocked by:** [02：完整景點內容與資訊狀態](02-complete-spot-reading.md)

**Status:** completed

**Parent:** [CarlTravel v1 規格](../../carltravel-v1/issues/11-carltravel-v1-spec.md)

- [x] 依 D 組合呈現 A 明體標題、B 緊湊首頁與篩選區、C 景點章節目錄；本票先完成版面，搜尋與篩選的實際行為由搜尋票交付，不以無效控件宣稱完成。
- [x] 首頁介紹資訊分類與審閱流程，列表依縣市北到南、同縣市名稱排序；景點目錄可用鍵盤跳到實際存在的分節，手機目錄可橫向捲動而頁面不溢出。
- [x] 完成關於頁、404及站內導覽；短版免責聲明連到關於頁，完整內容涵蓋官方確認、查證日期意義、未知及原作者觀點。
- [x] 頁尾提供短版授權，head 提供 license 關係；關於頁提供 CC BY-NC 4.0 範圍、署名方式、他人引文／官方事實例外及開放資料說明。
- [x] 儲存庫有程式 MIT 授權文件、獨立公開內容 CC BY-NC 4.0 宣告及兩者範圍說明；政府開放資料顯名在景點來源區呈現。
- [x] 首頁、景點頁、關於頁、404 在360、390、430、1366、1920像素無頁面水平捲動，axe零違規；標籤與狀態不只靠顏色辨認。
- [x] 建立 sitemap 白名單，只收首頁、正式景點與關於頁；404與測試／開發專用頁不進正式 sitemap。
- [x] 更新公開介面與無障礙驗證說明，實作正式頁面而不直接部署討論原型。
