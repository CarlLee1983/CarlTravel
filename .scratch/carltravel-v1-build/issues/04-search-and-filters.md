# 04: 搜尋與四種篩選

**What to build:** 讀者能搜尋景點並依出遊條件縮小結果，且搜尋不暴露不應收錄的內容。

**Blocked by:** [03：網站視覺、授權與基本頁面](03-site-design-and-license.md)

**Status:** ready-for-agent

**Parent:** [CarlTravel v1 規格](../../carltravel-v1/issues/11-carltravel-v1-spec.md)

- [ ] 首頁固定顯示搜尋框，提供縣市、類型、環境、年齡帶四種篩選；只列至少一個景點使用的值，少量景點時仍可操作。
- [ ] 年齡帶採0–2、3–6、7–12、13歲以上，相交範圍均掛上，unknown掛年齡未標示；涵蓋界線與開放上界案例。
- [ ] Pagefind只索引景點頁的名稱（最高權重）、縣市行政區、摘要、心得轉述、Agent建議與跟孩子一起看；官方數值、引文、來源清單、周邊安排不索引。
- [ ] 搜尋、組合篩選、清除與無結果提示可用鍵盤操作，結果維持既定排序與列表資訊；不提供最新排序。
- [ ] 使用實際建置索引查詢 fixture 的獨有文字，證明納入欄位可搜尋、排除欄位不可搜尋，關於頁與404不作景點結果。
- [ ] 新增操作後重跑受影響頁面的 axe 與五種寬度檢查；私人草稿與索引整合驗證由發布票完成，不要求草稿票反向依賴本票。
- [ ] 索引與篩選規則加入操作／架構文件，沿用既有資料契約而非另存第二份景點資料。
