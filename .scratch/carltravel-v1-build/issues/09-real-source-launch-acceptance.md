# 09: 真實來源完整上線驗收

**What to build:** 用一個合格真實來源證明完整流程可運作，Carl合入後自動部署並在正式網域看到核准內容。

**Blocked by:** [08：自動部署設定與上線關卡](08-deployment-readiness.md)

**Status:** ready-for-agent

**Parent:** [CarlTravel v1 規格](../../carltravel-v1/issues/11-carltravel-v1-spec.md)

- [ ] Carl提供符合收錄條件的真實來源；不符時記錄拒絕並另選合格來源，不能以拒絕或虛構資料代替發布成功。
- [ ] 依研究skill實際走過拆分確認、官方查證、本機草稿、送審與Carl明確審閱，核准不可讀時保留完整例外證據。
- [ ] 發布skill通過全部本機關卡並建立真實draft PR，核准內容與可公開摘要之外不外洩私人資料；CI全綠後才ready。
- [ ] Carl親自合入後，由既定流程自動部署；Agent只查狀態及驗證。至少一個真實核准景點在正式網域可讀，內容與核准版本相符。
- [ ] 驗證正式首頁／景點／關於／404、搜尋與篩選、sitemap、授權及免責；確認無草稿／修訂內容洩漏且沒有部署fixture。
- [ ] 彙整前序完整驗收矩陣的正反案例與五種寬度／axe結果；來源及環境未變的有效檢查可沿用，有修改則重跑受影響檢查。
- [ ] 記錄可公開PR、部署結果、公開頁與檢查證據，私人研究與核准細節留本機；更新驗收結果與操作文件。
- [ ] 需要Carl審閱／合入、帳號或網域操作未完成時，精確記錄待辦且保持本票未完成；部署失敗也不可宣稱產品驗收完成。
