# 01: 第一個景點可瀏覽

**What to build:** 讀者能由首頁進入一個景點，讀到基本資訊、官方出處與查證日期；維護者能重現這條最小完整流程。

**Blocked by:** None (can start immediately)

**Status:** done

**Parent:** [CarlTravel v1 規格](../../carltravel-v1/issues/11-carltravel-v1-spec.md)

- [x] 採用規格的 Astro 靜態輸出與 pnpm 基線，提供可執行的開發、建置、格式、型別、單元與瀏覽器驗證入口；逐票擴充同一套 verify，不建立平行驗證路徑。
- [x] 單一 YAML 景點經驗證載入後，在首頁呈現名稱、縣市行政區、類型、年齡與摘要，並能導向穩定 id 的景點頁；基本官方事實附有效出處及查證日期。
- [x] 使用規格最終內容模型的一個有效最小案例；尚未涵蓋的可選分節留給完整景點票，不另創需要日後替換的臨時資料格式。
- [x] 正式內容與測試／開發 fixture 載入可明確區分；虛構景點只供測試與開發展示，不成為正式待部署內容。零正式景點仍可建置與驗證。
- [x] 建立 fixture 驅動的端到端測試：首頁連結可到景點頁，資訊及出處可讀；無效基本資料在載入／建置入口失敗。
- [x] 提供啟動與驗證說明，記錄內容載入責任及 fixture 邊界；本票不部署、不製作真實景點。
