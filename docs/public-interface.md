# 公開介面與無障礙驗證

## 路由與導覽

| 路由 | 讀者用途 | 正式 sitemap |
| --- | --- | --- |
| `/` | 網站介紹、資訊分類、審閱流程與景點列表 | 收錄 |
| `/spots/<id>/` | 景點閱讀、章節目錄、出處與地圖連結 | 只收錄 `content/spots/` 的正式景點 |
| `/about/` | 資訊分類、完整免責聲明、授權範圍與署名方式 | 收錄 |
| 無效網址／`404.html` | 404 狀態、回景點索引與關於頁 | 不收錄，並標示 noindex |

共用頁首連向景點索引與關於頁，頁尾連向 `/about/#disclaimer` 與 `/about/#license`；所有頁面的 head 有 CC BY-NC 4.0 `rel="license"`。景點頁另有位於來源區之後的短版免責聲明。開放資料顯名沿用景點出處欄位，不混入本站內容授權。

## 版面與行為

首頁以精簡標題與搜尋作入口；桌面保留小幅情境插畫，700px 以下省略插畫，讓搜尋與首筆景點優先出現。搜尋在列表上方，縣市、類型、環境與年齡帶放在原生可展開的「篩選條件」，初始收合。選項只提供至少一個景點使用的值；當全部景點的年齡都未知時，隱藏沒有區分作用的年齡篩選。條件以交集套用，清除條件會清空搜尋與全部選項；已選條件也可逐項移除。

列表卡片在有已驗證插畫時顯示小幅縮圖：桌面置左、手機置於名稱旁，不附加縮圖圖說，保留描述圖片內容的替代文字；沒有插畫時維持完整文字版面。縮圖使用固定 3:2 滿版畫框、預留寬高、延遲載入及非同步解碼，比例與現有橫幅插畫一致；其他比例以置中裁切填滿，不加入白邊。列表卡片固定呈現名稱、地區與類型、摘要、環境與年齡資訊，另從同一筆 `familyChecklist` 顯示推車友善與雨天備案的「有／沒有／未知」、該清單的查證日期及逾一年提示，並連到景點頁親子清單核對出處與限制。未知不當作沒有，查證日期不當作有效期限，也不從摘要推定營運狀態或完整性評分。沒有改動景點資料模型或正式內容。

資訊分類說明放在列表之後。無結果時提供「重新瀏覽全部景點」按鈕，重設同一份表單並把焦點放回搜尋框；搜尋中透過文字及 `aria-busy` 表示尚未完成，保留可瀏覽的篩選結果。失敗時清楚說明文字搜尋無法使用，仍可調整條件或清除搜尋恢復瀏覽。

全站內容在寬螢幕收束至約 1360px，導覽以淡藍底標示目前頁面；共用色彩與字型 tokens，閱讀區採白底、深藍字，以淡藍及淡薰衣草紫輔助資訊分區；標題優先使用系統圓體並回退到系統黑體，內文優先使用本機繁體中文黑體，主按鈕採全圓角。品牌名稱只保留頁首的小字，頁尾以「台灣親子出遊筆記」收尾。不載入外部字型，不新增正式景點或虛構推薦。進入畫面的說明與列表有一次性短距離位移，文字與控制項保持完整對比；不支援腳本時內容照常可讀，減少動態偏好停用位移。

列表沿用內容載入器的縣市列舉順序，同縣市依名稱排序。景點頁左側章節目錄在桌面黏附於視窗上方，右側為單欄內容；900px 以下目錄回到上方，連結列換行排列。只有實際存在的章節才有目錄連結；原生錨點搭配可接收焦點的章節，支援鍵盤 Tab 與 Enter。頁面本身不以裁切溢出的方式掩蓋排版問題。景點摘要使用天空藍底，親子清單與官方事實採標籤／內容列，查證日期、過期提示、衝突狀態與來源引用各有明確層次。關於頁提供三個章節入口並收窄長文行寬；404 沿用核准插畫，提供回索引及關於頁的連結。

官方資訊、原作者心得與 Agent 建議使用文字標籤；未知、官方未公布、衝突、過期、原文無法讀取與設施狀態均保留可讀文字。顏色只輔助辨識。地圖是具名文字外連，不嵌入地圖。搜尋使用少量前端 JavaScript 與建置時產生的 Pagefind 索引；不載入外部字型。景點內頁的已驗證 AI 情境插畫附替代文字及可見說明「AI 生成情境插畫，非實際展區」。

## 網站插畫的公開邊界

`public/illustrations/family-outing.png` 為 2026-10-15 A 定稿核准的 AI 生成親子出遊情境插畫，不代表特定景點或實地照片。圖檔保留透明背景與尺寸屬性，首頁與 404 提供替代文字。共用 head 加入路徑圖案的內嵌 SVG favicon、主題色與分享標題／描述／插畫 metadata，沒有新增外部資產請求或套件。

`scripts/site-assets.ts` 固定這一個相對路徑與 SHA-256，公開資產和正式輸出檢查共用同一份規則。替換圖檔需先視覺審閱，再更新雜湊；改名、額外圖片、符號連結仍拒絕。景點插畫另由正式 YAML 宣告的雜湊綁定，輸出只接受對應 `/spot-illustrations/<id>.png` 的精確 PNG 位元組；一般公開資產白名單仍嚴格限定。撤回網站共用插畫時一併移除首頁引用、圖檔與白名單項目。

## 驗證入口與範圍

- `pnpm check`：Astro 與 TypeScript 型別。
- `node --experimental-strip-types --test tests/content.test.ts tests/output.test.ts`：縣市／同縣市排序、正式輸出頁面、sitemap 白名單與 fixture 隔離。以暫存內容測正式景點的收錄與漏列；不寫入正式景點目錄。
- `pnpm build:fixture && pnpm exec playwright test e2e/site-pages.spec.ts`：站內導覽、404 回應、授權與免責連結、手機鍵盤章節跳轉、桌面／手機首頁布局、fixture sitemap XML。
- 列表入口另在 **390、1024、1200、1366px** 驗證精簡標題、桌面插畫及搜尋區不重疊；手機可直接操作搜尋，進階條件收合且可用鍵盤展開。減少動態偏好下不播放動畫。
- 同一份瀏覽器測試對首頁、最小景點、完整景點、關於頁、404，分別在 **360、390、430、1366、1920px** 執行 axe 與頁面水平溢出檢查。完整景點測試另保留三種資訊、所有狀態、出處與開放資料顯名的內容驗證。
- `pnpm verify`：完整整合關卡，最後重新建置正式內容並檢查輸出。沒有直接部署討論原型或 fixture 的步驟。

自動無障礙檢查的範圍為 Chromium／axe，搭配鍵盤操作與桌面、手機截圖人工檢視；不宣稱涵蓋所有瀏覽器或螢幕閱讀器。真實來源、私人草稿索引隔離與正式部署驗收由後續票交付。

## 搜尋索引與模式

`src/content/search.ts` 將既有 `ageRange` 換算為相交的 0–2、3–6、7–12、13 歲以上年齡帶；unknown 只標示年齡未標示。首頁直接從同一批載入的景點產生可選值及卡片篩選屬性，沒有另一份手工維護的景點資料。

Astro 完成靜態頁面後，`scripts/search-index.ts` 只讀取當前模式載入器列出的景點 HTML，並透過 Pagefind 的 Node API 逐筆建立索引。輸出位於該模式的 `pagefind/` 目錄，正式與 fixture 分別在 `dist/` 與 `dist-fixture/`。不爬整個網站；零景點時產生空索引，不會退回收錄首頁、關於頁或 404。

索引根限制為景點頁的 `data-pagefind-body` 元素：名稱（權重 10，最高）、縣市行政區、摘要、心得轉述、Agent 建議與跟孩子一起看的事實／活動。日期、地址、設施清單、官方數值、出處連結、引文與周邊安排均在白名單之外。標題 metadata 只取景點名稱。具體依據為 [Pagefind 索引設定](https://pagefind.app/docs/indexing/)、[Node API](https://pagefind.app/docs/node-api/)與[文字權重](https://pagefind.app/docs/weighting/)。

瀏覽器按需載入索引，把匹配網址與當頁可用條件交集後，顯示／隱藏既有卡片，不依搜尋相關度重排。輸入採短暫延遲並支援中文組字；新查詢與清除會使舊回應失效。索引載入失敗時明示搜尋不可用，保留符合篩選的可瀏覽列表；未啟用 JavaScript 時保留全部景點並說明互動功能需要 JavaScript。

搜尋與條件以 `query`、`county`、`kind`、`setting`、`age` 網址參數保存。選項值依當頁實際選項驗證，未知值忽略；其餘網址參數及錨點保留。修改條件以 `history.replaceState` 更新同一筆瀏覽紀錄，避免每次輸入都增加上一頁步驟。載入、重新整理及瀏覽歷史切換時恢復條件，非同步搜尋仍以最新請求為準。

從列表開啟景點時，捲動位置、連結焦點及篩選區開合狀態保存在該筆瀏覽紀錄，返回時待搜尋結果確定後恢復；沒有使用 cookie、跨頁追蹤或裝置共用儲存。網址可分享條件，捲動位置不隨網址分享。原生新開索引頁與詳細頁上的「全部景點」入口仍開啟一般索引；瀏覽器上一頁用於回到原清單。無 JavaScript 時仍顯示全部景點，搜尋與篩選保持停用並說明原因。

完整搜尋以 `pnpm build:fixture && pnpm preview:fixture` 檢視。`pnpm dev:fixture` 提供即時頁面與本機篩選，但不產生 Pagefind 索引；輸入搜尋會顯示不可用提示。內容修改後需重新建置才能驗證搜尋，不沿用上一次建置的索引。正式預覽使用 `pnpm build && pnpm preview`。

`e2e/search.spec.ts` 使用實際建置索引查詢 fixture 中的獨有測試詞，並檢查索引文字沒有排除欄位；英文 `*probe` 僅是虛構 fixture 的驗證標記。另以中文名稱與縣市查詢驗證中文搜尋。中文查詢由 Pagefind 斷詞，可能回傳部分詞彙相符的結果，並非逐字子字串搜尋。


## 本機草稿預覽

一般 `pnpm dev` 的首頁與景點頁包含本機草稿；新內容標示「新草稿」，同 id 覆蓋標示「修訂中」，並顯示尚未發布及全站本機預覽提示。這些標記與內容不進正式建置。新增、修改、刪除草稿後開發服務會重啟清除路由快取，重新整理即可查看。fixture 開發不合併私人草稿；全文搜尋仍以建置後索引為準。操作、錯誤與私人檔案邊界見[開發文件](development.md#第-05-票本機草稿與修訂預覽)。

## 列表縮圖

`/spot-thumbnails/<id>.webp` 與既有原圖路由共用景點選擇與 `readIllustration` 驗證。建置時只讀取當前正式／fixture 景點，開發預覽才允許所選草稿；不接受自訂圖片路徑、外部 URL 或尺寸參數。來源 PNG 與 YAML 不變，也不把縮圖寫入 `public/` 或內容資料夾。

使用固定版本 `sharp`（0.35.5，原已由 Astro 間接使用，本次宣告為直接依賴）將已驗證像素縮至 336×224 WebP、品質 76，採 3:2 置中裁切、保留來源透明度，且不保留中繼資料。列表仍以較小 CSS 尺寸顯示；快取版本包含縮圖樣式版本及來源圖 SHA-256，避免樣式更新後沿用舊留白縮圖。

正式輸出檢查逐份從已驗證原圖重新生成縮圖並比對完整位元組，只允許正式景點對應的固定路徑；缺檔、修改、額外 WebP 或草稿產物均會阻擋。既有原 PNG 的雜湊驗證不變。回復縮圖功能時移除列表引用、縮圖路由／轉換模組、直接依賴及相應驗證，原始核准內容與圖片保留。
